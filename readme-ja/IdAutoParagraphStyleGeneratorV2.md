IdAutoParagraphStyleGenerator の別バージョンです。処理内容は同じで、フォント・文字サイズ・行送りごとに段落スタイルを自動生成します。

## 主な機能

- 参照する属性はフォント（ファミリー／スタイル）＋文字サイズ＋行送りのみ
- 内部の判定は pt に正規化
- テキストサイズ単位に合わせてスタイル名の表記が pt / Q に切り替わる

## 使い方

1. 対象のドキュメントを開く
2. スクリプトを実行する
3. 結果ダイアログで作成数と適用数を確認する

## 制限事項・メモ

- IdAutoParagraphStyleGenerator.jsx とほぼ同一の内容です。どちらか一方の利用を推奨します。
