# FileNameManager

アクティブなドキュメントのファイル名を、ベース・日付・タイトル・バージョンのセグメント単位で編集し、リネーム／別名保存／コピー保存を行います。

## 主な機能

- 動作モードは「ファイル名の変更」「別名で保存」（既定）「コピーを保存」
- ファイル名を base / date / text / version に分解し、元の出現順序を保ったまま編集
- タイムスタンプは「つけない / YYYYMMDD」、バージョンは「つけない / -vN / -v0N」から選択
- タイトルは「つけない / 親フォルダー / 指定」から選択
- 区切り記号を「変更しない / - / _」から選び、ファイル名全体で統一

## 使い方

1. 対象のドキュメントを開く
2. スクリプトを実行する
3. モードと各セグメントを指定して［OK］

## 制限事項・メモ

- 保存先は常に現在のファイルと同じフォルダです。未保存ドキュメントは保存先フォルダを選択します。
- バージョンは選択時に元の番号 +1（無ければ新規付与）になります。
- より多機能な Id-FileNameManager.jsx もあります。
