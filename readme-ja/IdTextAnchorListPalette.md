# テキストアンカーを一覧して表示

アクティブなドキュメントのテキストアンカー（［ハイパーリンク］パネルメニューの［新規ハイパーリンク先］で、種類を「テキストアンカー」にして作るもの）を、ページ・アンカー名・テキストの3列で、常駐パレットにページ順に一覧します。

［ハイパーリンク先のオプション］にはアンカー名しか出ず、どのページのどの段落にあるかは1つずつ移動して確かめるしかありません。このスクリプトなら、すべてのアンカーの場所と段落を1回で確認でき、パレットを開いたまま、ダブルクリックで次々にその位置へ移動できます。相互参照やハイパーリンクのリンク先を確かめるときに使えます。

### 主な機能

- 「ページ｜アンカー名｜テキスト」の3列のリストで表示（テキストはアンカーのある段落。長いものは「...」で切り詰める）
- ドキュメントページ・親ページ・ペーストボード・表の中・アンカー付きオブジェクトの中のテキストアンカーも対象
- 並びはドキュメントページ → 親ページ → ペーストボード → オーバーセットの順。同じページの中ではフレームの上から、同じ高さなら左から、同じフレームの中では文字の順
- ダブルクリックまたは［表示］で、そのアンカーのページを表示し、アンカーのある段落のテキスト（末尾の改行を除く）を選択する。パレットは開いたままなので、続けて別のアンカーへ移動できる
- 別のドキュメントを前面にしていても、一覧を作ったドキュメントに切り替えてから表示する
- ［更新］で、アクティブなドキュメントのアンカーを読み直す。選んでいたアンカーは、同じ名前があれば選び直す
- パレットのタイトルに件数を表示

### 使い方

1. ドキュメントを開いてスクリプトを実行する
2. 一覧でアンカーの場所とテキストを確認する
3. 移動したいアンカーをダブルクリックする（選んで［表示］をクリックしても可）。そのページが表示されて、アンカーのある段落のテキストが選択される
4. 続けて別のアンカーをダブルクリックする。アンカーを追加・削除したり、別のドキュメントを調べたりするときは［更新］をクリックする
5. 使い終わったら［閉じる］をクリックする

Esc で［閉じる］と同じ動作になります。

### 制限事項・メモ

- ドキュメントには変更を加えません（［表示］で表示するページと選択が変わるだけです）。
- 非表示のハイパーリンク先は一覧に入れません（スクリプト冒頭の `INCLUDE_HIDDEN_ANCHORS` を `true` にすると入れます）。
- 相互参照の「段落」を参照先にしたもの（段落のハイパーリンク先）や、URL・ページのハイパーリンク先は対象外です。
- オーバーセットのテキストにあるアンカーは、一覧には「オーバーセット」として出ますが、表示できません。
- ロック・非表示のレイヤーにあるアンカーは、テキストを選択できないことがあります。
- 空の段落にあるアンカーは、テキストの代わりにアンカーの位置にカーソルを置きます。
- 一覧は自動では更新されません。アンカーを追加・削除・移動したり、文章を編集したりしたら［更新］をクリックしてください。一覧を作ったドキュメントを閉じたり、アンカーを削除したりしたあとに表示しようとすると、［更新］を促すメッセージが出ます。
- パレットを開いたままスクリプトを実行し直すと、前のパレットを閉じて開き直します。
