段落スタイルに正規表現スタイル（GREP スタイル）を適用・管理します。IdGrepStyleApplier.jsx と同じ内容で、ファイル名だけが異なります。

## 主な機能

- 登録済みルールとカスタムルールの選択・追加
- 文字スタイルの選択と新規作成
- 適用先の段落スタイルを複数選択

## 使い方

1. 対象のドキュメントを開く
2. スクリプトを実行する
3. ルール・文字スタイル・適用先の段落スタイルを選んで［OK］

## 制限事項・メモ

- IdGrepStyleApplier.jsx と同一の処理です。どちらか一方の利用を推奨します。
