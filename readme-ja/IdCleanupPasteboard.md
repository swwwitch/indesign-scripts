# ページ外（ペーストボード上）のオブジェクトを削除

ページの外側（ペーストボード上）に置いたままのオブジェクトを、ドキュメントからまとめて削除します。

### 主な機能

- **対象**：現在の見開きページ（親ページを編集中ならその親ページ）／ドキュメント全体（初期値）／開いているすべてのドキュメント
- **この範囲の外側を削除**
  - 裁ち落とし：ドキュメント設定の裁ち落としより外側
  - 印刷可能領域：ドキュメント設定の印刷可能領域より外側
  - ページからの距離（初期値）：ページの端から指定した距離（mm）より外側。∧∨ボタンや↑↓キーで増減（shift で10の倍数へ、option で0.1ずつ）。ほかの単位（「1 in」など）や計算式を入れると mm に換算
  - 見開きでは、裁ち落とし・印刷可能領域の「ノド」と「小口」をページの左右に合わせて使い分け
- **オプション**
  - 親ページも対象にする：親ページのペーストボードも処理する（［現在の見開きページ］では使えない）
  - 連結されたテキストフレームは残す（初期値オン）：ほかのフレームと連結されたテキストフレームと、それを含むグループを削除しない
  - 非表示のオブジェクトは残す（初期値オン）：非表示のオブジェクトと、非表示のレイヤー上のオブジェクトを削除しない
  - ロックされたオブジェクトを削除：ロックされたオブジェクトもロックを解除して削除する
  - 削除する前に確認（初期値オン）：削除する数を表示し、［削除］［選択して表示］［キャンセル］から選ぶ
- **残すレイヤー**：リストで選んだレイヤー（⌘／Ctrl＋クリックで複数）のオブジェクトは削除しない。［開いているすべてのドキュメント］では、同じ名前のレイヤーを残す
- ダイアログの設定を記憶し、次回の初期値にする
- 実行後に削除した数を表示

### 使い方

1. ドキュメントを開いてスクリプトを実行する
2. 対象・範囲・オプション・残すレイヤーを選んで［OK］
3. 確認のダイアログで［削除］をクリック。削除する前に場所を見たいときは［選択して表示］

### 制限事項・メモ

- 範囲から完全に外れたオブジェクトだけを削除します。一部でもページ（範囲）に重なっているもの、辺が接しているだけのものは残します。
- 判定はオブジェクトの表示上の境界線（線幅を含む）で行います。グループは中身を1つずつではなく、グループ全体で判定します。
- ロックされたレイヤー上のオブジェクトは、オプションにかかわらず削除しません（削除数にも数えません）。
- ［選択して表示］は、候補がある最初の見開きを表示し、その見開きの候補を選択します（ロック・非表示のものは選択されません）。［開いているすべてのドキュメント］では使えません。
- 右綴じの見開きや、サイズの異なるページを含む見開きにも対応しています。
- 定規の単位（Q／H・ピクセルなどを含む）に関係なく動作します。調べる間だけ単位と定規の原点を切り替え、終了後に元に戻します。
- 残すレイヤーのリストには、現在のドキュメントのレイヤーが表示されます。
- 設定は `Folder.userData`（Mac は ~/Library/Application Support）の `IdCleanupPasteboard-prefs.txt` に保存します。
- ガイドは対象外です。
- 削除は1回の［取り消し］で元に戻せます。
