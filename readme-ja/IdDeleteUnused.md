# 使われていないスタイルとスウォッチを削除

[![Direct](https://img.shields.io/badge/Direct%20Link-IdDeleteUnused.jsx-ffcc00.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/jsx/misc/IdDeleteUnused.jsx)

[![English](https://img.shields.io/badge/README-English-4b8bbe.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/readme-en/IdDeleteUnused.md)

[![Direct](https://img.shields.io/badge/Back%20to%20home-All%20scripts-cccccc.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/README.md)

---

段落スタイル・文字スタイル・オブジェクトスタイル・表スタイル・セルスタイル・スウォッチ・親ページのうち、ドキュメント内で使われていないものを削除します。削除する前に一覧で確認でき、残したい項目はチェックを外せます。

## 主な機能

- 削除する項目（段落スタイル／文字スタイル／オブジェクトスタイル／表スタイル／セルスタイル／スウォッチ／親ページ）をチェックボックスで選択（初回はスウォッチのみON）
- 対象を「このドキュメント」「すべてのドキュメント」から選択
- 削除する前に、候補を一覧（種類・名前・ドキュメント）で表示。チェックを外した項目は残す
- スタイルは、テキストや表への適用だけでなく、他のスタイルやドキュメント設定から参照されているものも「使用中」として残す
- 子スタイルや、ほかの親ページの基準になっている親ページが未使用なら、元になっているスタイルや親ページも候補に入れる
- スウォッチは、グラデーションの分岐点や濃淡の元になっているカラーを残す（消すとグラデーションや濃淡が変わるため）
- オプション「空のスタイルグループを削除」で、空のスタイルグループ（削除で空になるものを含む）も削除
- ダイアログの選択状態を記憶し、次回の初期値にする
- 実行後に、種類ごとの削除数と合計を表示

## 使い方

1. ドキュメントを開いてスクリプトを実行する
2. 対象・削除する項目・オプションを選んで［OK］
3. 確認リストで、残したい項目のチェックを外して［削除］

### マウス操作

| 操作 | 動作 |
| --- | --- |
| `option` + 削除する項目のチェックボックスをクリック | その項目だけをON |
| その項目だけがONの状態で `option` + クリック | すべての項目をON |
| 確認リストの行をダブルクリック | その行のチェックを切り替え |
| 確認リストの［すべてON］／［すべてOFF］ | すべての行のチェックを切り替え |

## 「使用中」とみなす条件

| 項目 | 使用中とみなすもの |
| --- | --- |
| 段落スタイル | テキストへの適用、他の段落スタイルの「基準」「次のスタイル」、オブジェクトスタイル、セルスタイル、目次スタイル（見出し・項目・項目のスタイル）、脚注の設定、テキストの既定 |
| 文字スタイル | テキストへの適用、他の文字スタイルの「基準」、先頭文字スタイル・正規表現スタイル・行スタイル、箇条書き・自動番号、ドロップキャップ、目次スタイル（ページ番号・区切り文字）、脚注の設定、テキストの既定 |
| オブジェクトスタイル | ページアイテムへの適用、他のオブジェクトスタイルの「基準」、新規オブジェクトの既定 |
| 表スタイル | 表への適用、他の表スタイルの「基準」 |
| セルスタイル | セルへの適用、他のセルスタイルの「基準」、表スタイルの領域（ヘッダー行・フッター行・本文行・左端の列・右端の列） |
| スウォッチ | InDesign の「未使用のスウォッチ」に含まれないもの、グラデーションの分岐点、濃淡の元のカラー |
| 親ページ | ページへの適用、他の親ページの「基準」 |

## 制限事項・メモ

- ［段落スタイルなし］［基本段落］［なし］など、［ ］で囲まれた既定のスタイルは削除しません。
- 名前のないカラーは候補に入れません。［紙色］など削除できない既定のスウォッチが候補に出た場合は、削除せずに残します。
- 確認リストでチェックを外した項目から参照されている候補は、チェックが付いていても削除しません。結果の「残した項目」に数えます。
- スタイルを削除して新たに未使用になったスウォッチは、確認リストに出ません。もう一度実行すると候補に入ります。
- 段落に直接設定した先頭文字スタイルなど、スタイルとして定義されていない書式から参照されている文字スタイルは「使用中」と判定しません。
- 表スタイル・セルスタイルの判定で見るのはストーリー直下の表です。セルの中の表（入れ子の表）は調べません。
- テキストの検索は、非表示・ロック中のレイヤー、ロック中のストーリー、マスター、脚注も対象にします。変更した検索範囲の設定は処理後に元に戻しますが、［検索と置換］の検索条件は空になります。
- 取り消しはドキュメントごとに1回でまとめて戻せます。
- ダイアログの選択状態は `IdDeleteUnused-prefs.txt`（ユーザーデータフォルダー）に保存されます。
