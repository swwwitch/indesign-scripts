# パネルを検索して表示

[![Direct](https://img.shields.io/badge/Direct%20Link-IdPanelLauncher.jsx-ffcc00.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/jsx/misc/IdPanelLauncher.jsx)

[![English](https://img.shields.io/badge/README-English-4b8bbe.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/readme-en/IdPanelLauncher.md)

[![Direct](https://img.shields.io/badge/Back%20to%20home-All%20scripts-cccccc.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/README.md)

---

［ウィンドウ］メニューのパネルを、サブメニュー（［カラー］［書式と表］など）の中まで展開して1つのリストに並べます。検索欄で絞り込み、選んだパネルを表示します。

### 主な機能

- ［ウィンドウ］メニューのパネルを「名前｜印｜分類｜表示中」の4列のリストで表示（メニューの並び順）
  - サブメニューの中の項目も展開し、分類の列にサブメニュー名を表示
  - 表示中のパネルには「✓」
  - 印の列には ♥（よく使う）か ♢（あまり使わない）
  - エクステンションのパネル（CC ライブラリ、Overlays など）も対象
- 検索欄で名前と分類を絞り込み（入力するたびに絞り込む）
  - 空白で区切ると、すべての語を含むものに絞る（例：「書式 文字」）
  - 大文字小文字を区別しない。ひらがなはカタカナとして探し、漢字の名前は読みでも探す（「から」で［カラー］［グラデーション］［スウォッチ］、「しょしき」で［書式と表］の中のパネル）
  - 検索欄の右の（×）ボタンで検索をクリア
- パネルに印を付けて絞り込み
  - リストでパネルを選び、左下の ♥ で ♥（よく使う）、♢ で ♢（あまり使わない）を付ける。選んだパネルがすべて付いていれば、もう一度押すと外す
  - ♥ と ♢ はどちらか一方。複数のパネルにまとめて付けられる
  - 絞り込みのラジオボタン：**すべて**／**♥ よく使う**（♥ のパネルだけ）／**♢ を除く**（♢ のパネルを隠す）
  - 印と絞り込みは次回も引き継ぐ
- セットのボタンで、決まった組み合わせのパネルをまとめて表示（絞り込み・検索・選択に関係なく、ダイアログを閉じて表示）
  - **表**：セルスタイル・表スタイル・表
  - **テキスト**：文字・段落・文字スタイル・段落スタイル・字形・テキストの回り込み
  - **ブック**：相互参照・ハイパーリンク
- 並び順をラジオボタンで切り替え
  - **デフォルト**：［ウィンドウ］メニューの並び（サブメニューの中身はサブメニューの位置）
  - **あいうえお順**：パネル名の読みの順（英字が先。漢字は読みに置き換えて並べる）
  - 並び替えても、選んでいたパネルは選んだまま
- 絞り込むと先頭のパネルを選択するので、そのまま Enter で表示できる
- 複数のパネルを選んでまとめて表示
- 表示中のパネルを選ぶと、いったん閉じて開き直し、前面に出す
- ダイアログのタイトルに表示中の件数を表示

### 使い方

1. スクリプトを実行する
2. 検索欄にパネルの名前の一部を入れる
3. 次のどれかで表示する
   - Enter／Return
   - リストの項目をダブルクリック
   - ［表示］をクリック

検索欄で ↓ を押すとリストへ移ります。⌘（Ctrl）／Shift＋クリックで複数選べます。

### 制限事項・メモ

- ［ウィンドウ］メニューの、1本目と2本目の区切り線のあいだ（パネルが並ぶ区画）を一覧にします。［アレンジ］［ワークスペース］、［アプリケーションフレーム］［コンテキストタスクバー］、ドキュメントのウィンドウ名は出しません。区切り線が見つからないときは、［ウィンドウ］メニューの項目をすべて出します。
- 表示はメニューの項目を選ぶのと同じです（`app.menuActions.itemByID(…).invoke()`）。InDesign の［ウィンドウ］メニューは表示／非表示の切り替えなので、表示中のパネルは2回選んで開き直します。
- あいうえお順と検索で使う漢字の読みは、InDesign 2026 の日本語版のパネル名に合わせてスクリプト内の表（KANJI_READINGS）に持っています。表に無い漢字は文字コード順になります。長音（ー）と中黒（・）は無視します。
- 表示中の印（✓）は、スクリプトを実行した時点のメニューのチェックです。
- セットのパネルはパネル名（日本語版・英語版）で探します。見つからなかったパネルは、閉じたあとに「表示できなかったパネル」として出します。組み合わせはスクリプト内の PANEL_SETS で変えられます。
- ♥・♢ の印と絞り込みは `~/Library/Application Support/IdPanelLauncher-settings.txt`（`Folder.userData`）に保存します。印はパネルの分類と名前で覚えるので、InDesign の表示言語を切り替えると引き継がれません。
- モーダルダイアログの表示中はパネルを開けないため、ダイアログを閉じてから表示します。
- 繰り返し使う前提で `#targetengine` を指定しています。キーボードショートカットを割り当てると便利です。
- Esc でダイアログを閉じます。
