# テキスト・表・オブジェクトのスタイルオーバーライドを一括消去

[![Direct](https://img.shields.io/badge/Direct%20Link-IdClearStyleOverrides.jsx-ffcc00.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/jsx/style/IdClearStyleOverrides.jsx)

[![Direct](https://img.shields.io/badge/Back%20to%20home-All%20scripts-cccccc.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/README.md)

テキスト・表・オブジェクトに適用されているスタイルのオーバーライド（手動で加えた書式変更）を、まとめて消去します。スタイルパネルで1か所ずつ消していく作業を、ドキュメント全体・ストーリー・選択範囲のいずれかに対して一度に実行できます。

![ダイアログ。上から対象、テキスト（段落スタイルと文字スタイル）、表スタイルとセルスタイル、オブジェクトスタイルの4パネル](../png/ss-992-1142-144-20260920-142250.png)

## 主な機能

- 対象を「ドキュメント」「ストーリー」「選択範囲」から選択
- テキスト／表スタイルとセルスタイル／オブジェクトスタイルの3種類を、それぞれ個別にON・OFF
- 段落・文字・表・セル・オブジェクトの各スタイルで、処理する箇所を絞り込み
- 消去するオーバーライドを「両方」「段落のみ」「文字のみ」から選択
- 表スタイルとセルスタイルのオーバーライドを同時に消去
- 脚注、マスターページ上のテキスト、表の中のテキストも対象
- 処理対象が1つもない設定では実行ボタンを無効化
- 1回の取り消し（⌘Z）でまとめて元に戻せる

## 使い方

1. ドキュメントを開く（「ストーリー」「選択範囲」を使う場合は、対象を選択しておく）
2. スクリプトを実行する
3. 対象・消去するオーバーライド・絞り込みを指定して［オーバーライドを消去］

## 対象

| 選択 | テキスト・表 | オブジェクト |
| --- | --- | --- |
| ドキュメント | ドキュメント全体 | 全フレーム（マスターページ上を含む） |
| ストーリー | 選択箇所が属するストーリー全体（連結したフレームすべて） | そのストーリーのテキストフレーム |
| 選択範囲 | 選択しているテキスト（セル選択・フレーム選択も可） | 選択しているオブジェクト |

「選択範囲」でセルを選んでいる場合は、選んだセルのセルスタイルのオーバーライドと、そのセルが属する表の表スタイルのオーバーライドが消去されます（表の他のセルには触れません）。表全体のセルを処理したいときは、表を含むフレームを選ぶか「ストーリー」を選んでください。

## 消去するオーバーライド

InDesignは段落スタイルからのズレを、段落レベルと文字レベルの2種類に分けて持っています。

| | 段落レベル | 文字レベル |
| --- | --- | --- |
| 主な属性 | 行揃え、インデント、段落前後のアキ、タブ、ドロップキャップ、段落境界線、分離禁止オプション、ハイフネーション、禁則処理セット、文字組みアキ量設定 | フォント・サイズ・ウェイト、行送り、カーニング、トラッキング、文字カラー、ベースラインシフト、長体・平体 |

行送りが文字レベル側にあるのは直感に反しますが、InDesignでは行送りは文字属性です（1つの段落内で混在できるため）。

段落スタイルパネル下部の「オーバーライドを消去」ボタンの修飾キーと同じ区分です。

| このスクリプト | 段落スタイルパネル |
| --- | --- |
| 両方 | そのままクリック |
| 段落のみ | ⌘＋クリック |
| 文字のみ | ⌘＋shift＋クリック |

### 具体例

段落スタイル「本文」を当てた段落を、手で「中央揃え」かつ「一部を太字」にした状態のとき:

- **両方** → 左揃えに戻り、太字も外れる
- **段落のみ** → 左揃えに戻るが、太字は残る
- **文字のみ** → 中央揃えのままだが、太字は外れる

「レイアウト調整で入れた行揃えやアキは残したいが、コピペで混入したフォント指定だけ落としたい」といった場面が**文字のみ**の使いどころです。

## 制限事項・メモ

- 適用済みの文字スタイルは解除されません。消えるのは手動で加えた書式（オーバーライド）だけです。文字スタイル自体を外したい場合は、別途 `[なし]` を適用してください。
- ロックされたレイヤー、ロックされたストーリーは対象外です。
- 対象が「選択範囲」のとき、テキストにカーソルを置いただけの状態は「選択なし」として扱われます。そのストーリー全体でよければ「ストーリー」を選んでください。
- スタイルのドロップダウンには `[なし]` も並びます。スタイルが適用されていない箇所だけを処理したいときに使えます。
- 処理対象が多いドキュメントでは時間がかかります。
