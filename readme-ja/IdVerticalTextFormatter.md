# 縦組みの欧文回転・縦中横・数字の書き換えをまとめて適用

[![Direct](https://img.shields.io/badge/Direct%20Link-IdVerticalTextFormatter.jsx-ffcc00.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/jsx/text/IdVerticalTextFormatter.jsx)

[![English](https://img.shields.io/badge/README-English-4b8bbe.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/readme-en/IdVerticalTextFormatter.md)

[![Direct](https://img.shields.io/badge/Back%20to%20home-All%20scripts-cccccc.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/README.md)

選択したテキストを縦組みにし、［縦組み中の欧文回転］［縦中横］・数字の書き換え（全角・漢数字・和暦）・禁則・文字組みなどをまとめて適用します。Illustrator 版 [VerticalTextFormatter](https://github.com/swwwitch/illustrator-scripts/blob/master/readme-ja/VerticalTextFormatter.md) の InDesign 版です。

### 主な機能

- 「簡易」「詳細」「ウィザード」の3つのモード（ダイアログボックスの最上部の左で切り替え）と、プリセット（組み込み7種、保存・削除）
- 「欧文回転・縦中横」：縦組み中の欧文回転（○文字以上の欧文は除く）／数字を縦中横（2桁・3桁・4桁、桁区切り・小数点の隣は除く）／大文字の英字（2〜3字）を縦中横／「!!」「!?」を縦中横／字数に合わせた等幅字形（2字は等幅半角、3字は等幅三分、4字は等幅四分）
- 「文字の変換」：桁区切り（「、」にする／取る／そのまま）／小数点「.」→「・」／範囲の「-」「~」→「〜」／全角英数字を半角に／記号を全角に／引用符を〝〟に／「!」「?」を全角に／1文字の英字を全角に／3文字以内の大文字の英単語を全角に（PDF → ＰＤＦ）／○文字以下の英単語を全角に
- 「数字」：1桁の数字を全角に／3桁以上の数字を全角に（2026 → ２０２６）／縦中横以外の数字を全角に／単位を組文字に／西暦を和暦に／漢数字を算用数字にそろえる／漢数字に変換（1字ずつ・十百千・万億兆、0を「零」に、千を「一千」に）／番号のハイフン
- 「文字・段落」：禁則処理セット・文字組みアキ量設定（ドキュメントにあるもの。既定は弱い禁則・行末約物半角）／行送り（自動行送りの％）／全角英数字にプロポーショナルメトリクス／「一」を詰めない／高さを文字サイズの整数倍に／フレームを自動サイズ調整（幅のみ・右上基準）
- 「確認用の色分け」：全角の英数字と「！？」を赤、半角を青、等幅字形を緑、ほかを［黒］で塗る（スウォッチ「確認用_全角」などを追加）
- ［変換の確認...］で、今の設定で変わる箇所を別のダイアログボックスで一覧表示
- すでに縦組みのテキストは、横組み用に戻してから設定に合わせて適用するので、設定を変えて再実行できる（漢数字・和暦は、前回それらをオンで処理したストーリーだけ戻す）
- 処理全体が1回の取り消しにまとまる
- 設定は保存され、次に開いたときに戻る。日本語／英語の自動切り替え

### 使い方

1. テキストフレームを選択する（文字ツールで範囲を選んでもよい）
2. スクリプトを実行し、ダイアログボックスで項目を選ぶ
3. ［変換の確認...］で変わる箇所の一覧を確かめ、［OK］をクリックする

### 制限事項・メモ

- テキストフレームを選んだときは、連結したフレームも含めてストーリー全体が対象です。縦組み・横組みはストーリーごとに変わります（文字の範囲を選んだときも）。
- 表のセル・脚注の中の文字は対象にしません。ロック・非表示（レイヤーも）のテキストフレームは対象にしません。
- 文字数が変わる書き換え（3,000 → 三千 など）では、書き換えた部分は先頭の文字の書式になります。
- 処理の最後に、行送りを「自動」、自動カーニングを「なし」（0）、行揃えを「均等配置（最終行上揃え）」にします。
- ［高さを文字サイズの整数倍に］は、回転・シアーしたフレームは変えません。フレームの自動サイズ調整がオンのときは、高さが自動サイズ調整で決まります。
- ［フレームを自動サイズ調整］は、連結していないテキストフレームだけが対象です。
- 簡易モードとウィザードでは、禁則処理セット・文字組みアキ量設定・行送りは変えません（ウィザードの［段落を縦組み用に整える］を除く）。
- 処理したことは、ストーリーのラベル（キー VerticalTextFormatter）に記録します。
- Illustrator 版との違い：欧文回転・縦中横・字形は DOM で直接設定します（一時アクションは使いません）。禁則・文字組みはドキュメントの一覧から選びます（Illustrator の「弱い禁則v2」「ベタ組み」は InDesign にないため、既定は弱い禁則・行末約物半角）。
- 設定は `~/Library/Application Support/indesign-scripts/IdVerticalTextFormatter.json`、プリセットは同じフォルダーの `IdVerticalTextFormatterPresets.json` に保存します。
