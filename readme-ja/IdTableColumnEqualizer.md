カーソルのある表の幅を、親テキストフレームの幅にそろえます。

## 主な機能

- 親方向にたどってテキストフレームを探し、その幅を表に適用
- 列幅は InDesign の既定動作に従って比例配分される

## 使い方

1. 表内にカーソルを置く
2. スクリプトを実行する

## 制限事項・メモ

- 表がテキストフレーム内にない場合はメッセージを表示して終了します。
