# ZebraRowFill

選択した表セルに対して、選択範囲内の行の並びを基準に交互の塗り（縞模様）をプレビュー付きで適用します。

## 主な機能

- 奇数行・偶数行それぞれにカラーと濃淡（0〜100%）を設定
- ［交換］ボタンで奇数行と偶数行の設定を入れ替え
- 行のスキップ・列のスキップで、選択範囲の上／左から指定数を対象外にする
- 数値は ↑↓ キーで ±1、Shift + ↑↓ で ±10。濃淡スライダーは通常 1%、Shift 10%、Option 5% 刻み
- 「なし」「紙色」を選ぶと濃淡 UI を自動的にディム表示

## 使い方

1. 塗りを設定したい表セルを選択する
2. スクリプトを実行する
3. 奇数行・偶数行のカラーと濃淡、スキップ数を指定して［OK］

## 制限事項・メモ

- カラーリストでは Registration を常に非表示にし、Paper は「紙色」、None は「なし」と表示します。
- スキップ対象のセルは、ダイアログ起動時のカラーに戻ります。
- キャンセル時はプレビューで加えた変更を自動で巻き戻します。
