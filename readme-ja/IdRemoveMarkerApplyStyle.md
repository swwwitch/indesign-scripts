# Markdown の目印を削除してスタイルを適用

行頭の目印（Markdown の見出し・箇条書き・番号リストなど）を手がかりに段落スタイルと文字スタイルを適用し、その目印を後ろに続くスペースごと削除します。目印は検索対象から自動判別でき、対象箇所の件数を確かめてから実行できます。

## 主な機能

- 検索文字列の指定は「文字列を指定」と「自動判別」から選択
- 自動判別は検索対象の段落を走査し、行頭に 2 回以上繰り返す目印を多い順に一覧表示（件数付き）。検索対象を変えると判定し直します
- 拾える行頭記号：`#` `*` `-` `>` `+` `~` `=` `|` `_` `` ` `` と、箇条書きに使う `●` `○` `◎` `◆` `◇` `■` `□` `▲` `△` `▼` `▽` `★` `☆` `・` `※`、全角の `＊` `＃` `－` `＋` `＞`
- 番号リストは `1.` `1)` `（一）` `一.` `一、` `一）` に対応（数字が変わるため GREP で検索）。漢数字は十・百・千を含みます
- 太字 `**文字列**` は囲みとして判定し、前後の `**` を削除
- 見つかった段落に段落スタイルと文字スタイルを適用し、目印を削除。目印に続く半角／全角スペース・タブも一緒に削除します
- 「検索文字列」パネルの「対象箇所」に、現在の設定で見つかる件数を表示。入力や検索対象を変えるたびに数え直し、実際の検索対象に合わせて非表示レイヤー・ロックされたレイヤーのテキストは除きます
- 「Markdown」パネルの「見出しレベルに合わせる」は、選んだ見出しレベルに対応する段落スタイル（`h3` / `heading 3` など）を自動で選択（既定 ON）
- 同じく「連続適用（見出しのみ）」は、`#` 〜 `######` の 6 レベルを一度に処理し、各レベルへ `h1` 〜 `h6` を割り当て
- 検索対象はストーリー／ドキュメント／すべてのドキュメント（ラジオボタンで選択）
- スタイルグループ内のスタイルも選択・適用の対象
- 各項目にツールチップを表示（マウスを重ねると動作の説明が出ます）
- 一連の処理は 1 回の取り消し（Cmd+Z）で元に戻せます

## 使い方

1. 目印を含むテキストにカーソルを置く（ドキュメント全体を対象にする場合は開くだけで可）
2. スクリプトを実行する
3. 検索文字列・適用するスタイル・検索対象を指定して［OK］

## 制限事項・メモ

- 自動判別で選んだ行頭記号は行頭に固定して検索します（GREP の `^`）。段落の途中にある同じ記号は削除しません。太字の `**` だけは囲みなので行頭固定なしで検索します。
- 「文字列を指定」は行頭に固定しませんが、同じ文字が続く並びの一部には一致しません。`##` は `### 見出し` に一致しません。
- 目印に続く半角スペース・全角スペース・タブは、連続していてもまとめて削除します。区切りが無い行（`##見出し`）も対象です。
- 見出しに対応する段落スタイルは `h3` → `H3` → `heading 3` → `Heading 3` の順に探し、最初に見つかったものを使います。
- 連続適用中は「検索文字列」「適用するスタイル」パネルがディム表示になり、その設定（文字スタイルを含む）は使いません。
- 連続適用で、対応する段落スタイルが無い見出しレベルは静かに飛ばします。h1〜h3 しか用意していないドキュメントでもエラーにはなりません。
- 「ストーリー」はテキストの選択またはカーソル位置が必要です。未選択のまま実行すると対象が見つからずエラーになります。
- 「すべてのドキュメント」では、スタイルの一覧はアクティブドキュメントのものです。同名の段落スタイルが無い書類はスキップし、結果に書類名を表示します。
- 取り消しはドキュメント単位です。「すべてのドキュメント」で実行した場合、書類ごとに取り消してください。
- 検索オプション（半角と全角を区別／ひらがなとカタカナを区別／脚注・マスターページを含む など）はスクリプト側で設定し、前回の「検索/置換」の設定は引き継ぎません。検索はすべて GREP なので、大文字と小文字は常に区別します。
- 非表示レイヤー・ロックされたレイヤー・ロックされたストーリーは検索対象外です。自動判別の件数も、非表示レイヤー・ロックされたレイヤーのテキストを除いて数えます。
- 件数の数え方は 2 通りです。自動判別の候補と、そのときの「対象箇所」は段落数で、`##見出し` と `## 見出し` は同じ目印、太字は 1 段落に 2 か所あっても 1 と数えます。「文字列を指定」のときの「対象箇所」と完了メッセージは削除する目印の数なので、太字では 1 か所につき 2 で加算されます。
- 文字スタイルは目印を含む段落全体に適用されます。囲まれた文字列だけに適用する動作ではありません。

### v1.1.0（2026-09-10）

動作

- 目印に続く半角／全角スペース・タブを、目印と一緒に削除するように変更
- 「文字列を指定」も GREP で検索するようにし、同じ文字が続く並びの一部（`##` と `### 見出し`）に一致しないように変更
- `##見出し` と `## 見出し` を同じ目印として数えるように変更
- 自動判別の件数から、非表示レイヤー・ロックされたレイヤーのテキストを除外

ダイアログ

- 「検索文字列」パネルに「対象箇所」を追加し、現在の設定で見つかる件数を表示
- 検索対象を独立したパネルに分け、ドロップダウンから縦並びのラジオボタンに変更
- 「オプション」パネルを「Markdown」に、「置換スタイル」パネルを「適用するスタイル」に改称
- 検索対象のツールチップを項目ごとに分け、スタイルの行ラベルにもツールチップを追加

文言

- ダイアログ名と取り消し名を「目印を削除してスタイルを適用」に変更（文字スタイルも適用するため）

- 完了メッセージを「%1箇所の目印を削除しました。」に変更
