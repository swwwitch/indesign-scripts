# Markdown の目印を削除して段落スタイルを適用

行頭の目印（Markdown の見出し・箇条書き・番号リストなど）を手がかりに段落スタイルと文字スタイルを適用し、その目印を削除します。目印は検索対象から自動判別して候補に並べられます。

## 主な機能

- 検索文字列の指定は「文字列を指定」と「自動判別」から選択
- 自動判別は検索対象の段落を走査し、行頭に 2 回以上繰り返す目印を多い順に一覧表示（件数付き）。検索対象を変えると判定し直します
- 拾える行頭記号：`#` `*` `-` `>` `+` `~` `=` `|` `_` `` ` `` と、箇条書きに使う `●` `○` `◎` `◆` `◇` `■` `□` `▲` `△` `▼` `▽` `★` `☆` `・` `※`、全角の `＊` `＃` `－` `＋` `＞`
- 番号リストは `1.` `1)` `（一）` `一.` `一、` `一）` に対応（数字が変わるため GREP で検索）。漢数字は十・百・千を含みます
- 太字 `**文字列**` は囲みとして判定し、前後の `**` を削除
- 見つかった段落に段落スタイルと文字スタイルを適用し、目印を削除
- 「Markdown のレベルを合わせる」は、選んだ見出しレベルに対応する段落スタイル（`h3` / `heading 3` など）を自動で選択（既定 ON）
- 「Markdown の連続適用（見出し）」は、`#` 〜 `######` の 6 レベルを一度に処理し、各レベルへ `h1` 〜 `h6` を割り当て
- 検索対象はストーリー／ドキュメント／すべてのドキュメント
- スタイルグループ内のスタイルも選択・適用の対象
- 各項目にツールチップを表示（マウスを重ねると動作の説明が出ます）
- 一連の処理は 1 回の取り消し（Cmd+Z）で元に戻せます

## 使い方

1. 目印を含むテキストにカーソルを置く（ドキュメント全体を対象にする場合は開くだけで可）
2. スクリプトを実行する
3. 検索文字列・置換スタイル・オプションを指定して［OK］

## 制限事項・メモ

- 検索は行頭に固定しています（GREP の `^`）。段落の途中にある同じ記号は削除しません。太字の `**` だけは囲みなので行頭固定なしで検索します。
- 見出しに対応する段落スタイルは `h3` → `H3` → `heading 3` → `Heading 3` の順に探し、最初に見つかったものを使います。
- 連続適用中は「検索文字列」「置換スタイル」パネルがディム表示になり、その設定（文字スタイルを含む）は使いません。
- 連続適用で、対応する段落スタイルが無い見出しレベルは静かに飛ばします。h1〜h3 しか用意していないドキュメントでもエラーにはなりません。
- 「ストーリー」はテキストの選択またはカーソル位置が必要です。未選択のまま実行すると対象が見つからずエラーになります。
- 「すべてのドキュメント」では、スタイルの一覧はアクティブドキュメントのものです。同名の段落スタイルが無い書類はスキップし、結果に書類名を表示します。
- 取り消しはドキュメント単位です。「すべてのドキュメント」で実行した場合、書類ごとに取り消してください。
- 検索オプション（大文字と小文字を区別／半角と全角を区別／脚注・マスターページを含む など）はスクリプト側で設定し、前回の「検索/置換」の設定は引き継ぎません。
- 自動判別の件数は段落数です。太字は 1 段落に 2 か所あっても 1 と数えます。一方、完了メッセージの件数は削除した目印の数なので、太字では 1 か所につき 2 で加算されます。
- 文字スタイルは目印を含む段落全体に適用されます。囲まれた文字列だけに適用する動作ではありません。
