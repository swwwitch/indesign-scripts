# カーソル位置やフレームにQRコードを挿入

[![Direct](https://img.shields.io/badge/Direct%20Link-IdInsertQRCode.jsx-ffcc00.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/jsx/document/IdInsertQRCode.jsx)

[![English](https://img.shields.io/badge/README-English-4b8bbe.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/readme-en/IdInsertQRCode.md)

[![Direct](https://img.shields.io/badge/Back%20to%20home-All%20scripts-cccccc.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/README.md)

カーソル位置・選択したフレーム・ページの中央のいずれかに、大きさとカラーを指定して QR コードを挿入します。

［オブジェクト］→［QR コードを生成］では、作ったあとに配置して大きさを整える必要があります。このスクリプトなら、文中のカーソル位置へインラインで入れたり、決まった大きさでページに置いたりするところまで1回で済みます。

### 主な機能

- 挿入先は選択から自動で決まる

  | 選択 | 挿入先 |
  | --- | --- |
  | テキスト内のカーソル | カーソル位置（インラインのアンカー付きオブジェクト） |
  | テキスト | 選択したテキストの直後（テキストは残す） |
  | グラフィックフレーム（長方形・楕円形・多角形）またはその中の画像 | そのフレーム（大きさはフレームのまま） |
  | なし | 表示中のページの中央 |

- 種類は「Web ハイパーリンク」と「プレーンテキスト」
- テキストを選択して実行すると、そのテキストが内容の初期値になる（URL でなければプレーンテキストを選んだ状態で始まる）
- 大きさは mm で指定（初期値 20 mm）。∧∨・↑↓キーで増減でき、別の単位で入力しても換算される
- カラーはドキュメントのスウォッチから選択（初期値は［黒］、色見本付き）
- 挿入後は QR コードのフレームを選択した状態になる
- 1回の取り消しで戻せる

### 使い方

1. QR コードを入れたい位置にカーソルを置くか、フレームを選択する（ページの中央に入れるなら何も選択しない）
2. スクリプトを実行する
3. 種類を選び、URL またはテキストを入力する
4. 大きさとカラーを指定して［OK］をクリックする

### 制限事項・メモ

- カーソル位置と選択したフレームへの挿入は、実機での動作が未確認です。
- ペーストボード上のテキストやオーバーセットのテキストには挿入できません。
- テキストフレームを選択して実行しても挿入できません。カーソルを置くか、選択を解除してください。
- 内容のあるフレームを選択したときは、置き換えてよいかを確認します（既定は［いいえ］）。
- テキストフレームや行の高さが足りないと、挿入した QR コードがオーバーセットになります。オーバーセットの QR コードは InDesign が落ちる原因になるおそれがあるので、枠を広げてください。
- 内容は1行です。改行を含むテキストや、アンカー付きオブジェクトを含むテキストを選択したときは、内容の初期値に使いません。
- ［なし］［紙色］とグラデーションのスウォッチはカラーの一覧に出しません。
- 電子メール・テキストメッセージ・名刺の QR コードは、［オブジェクト］→［QR コードを生成］を使ってください。
