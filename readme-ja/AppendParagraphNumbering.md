# AppendParagraphNumbering

同じテキストが同じ段落スタイルで繰り返すとき、末尾に連番を付けます。親見出しの階層を考慮して、親単位で重複を判定します。

## 主な機能

- 段落スタイルを一覧表示し、チェックボックスで対象を絞り込み
- ストーリー／ドキュメントの範囲切り替え
- 全角／半角括弧の切り替え（日本語 UI のみ）
- 既存のナンバリングを削除する［削除］ボタン

## 使い方

1. 対象のドキュメントを開く
2. スクリプトを実行する
3. 対象の段落スタイルと範囲を選んで［OK］

## 制限事項・メモ

- 対象は開いているアクティブドキュメントです。
- 番号の付与も削除も 1 回の取り消しで元に戻せます。

## 更新履歴

### v1.2.0（2026-08-13）

- 親見出しが見つからない段落が対象から漏れていた問題を修正。見出しとして扱われるのは `HEADING_LEVEL_MAP` にある名前（`h1`〜`h6` / `Heading 1`〜`Heading 6`）だけなので、それ以外の見出しスタイルを使った文書では対象が 1 件も出ませんでした
- 空段落や 1 文字の見出しがあると、選んだ対象が処理されないことがある問題を修正
- 日本語 UI で［キャンセル］がダイアログを閉じない問題を修正
- グループ内に配置された親ページのテキストフレームを、対象から正しく除外するように修正
- ［削除］の実行時にダイアログを閉じるように変更（実行後もリストが古いまま残っていました）
- ドキュメント未オープン時と、［ストーリー］指定で未選択のときのメッセージを追加
- 解析処理を高速化
