# AppendParagraphNumbering

同じテキストが同じ段落スタイルで繰り返すとき、末尾に連番を付けます。親見出しの階層を考慮して、親単位で重複を判定します。

## 主な機能

- 段落スタイルを一覧表示し、チェックボックスで対象を絞り込み
- ストーリー／ドキュメントの範囲切り替え
- 全角／半角括弧の切り替え（日本語 UI のみ）
- 既存のナンバリングを削除する［削除］ボタン

## 使い方

1. 対象のドキュメントを開く
2. スクリプトを実行する
3. 対象の段落スタイルと範囲を選んで［OK］

## 制限事項・メモ

- 対象は開いているアクティブドキュメントです。
- 番号の付与も削除も 1 回の取り消しで元に戻せます。
