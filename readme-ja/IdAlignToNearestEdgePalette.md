# 移動方向でいちばん近いガイド・マージン・ページ・裁ち落としに揃えるパレット

[![Direct](https://img.shields.io/badge/Direct%20Link-IdAlignToNearestEdgePalette.jsx-ffcc00.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/jsx/frame/IdAlignToNearestEdgePalette.jsx)

[![English](https://img.shields.io/badge/README-English-4b8bbe.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/readme-en/IdAlignToNearestEdgePalette.md)

[![Direct](https://img.shields.io/badge/Back%20to%20home-All%20scripts-cccccc.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/README.md)

---

選択したオブジェクトを、パレットのボタンで選んだ方向へ動かし、その方向でいちばん近いガイド・マージンガイド・ページのエッジ・裁ち落としに辺を揃えます。中央のボタンは、ページかマージンの内側の中央に揃えます。

### 主な機能

- 3×3 の9つのボタンと、その下の2つのボタンで揃え方を選ぶ（ボタンの絵は、揃える先の線とオブジェクト）
  - 上・下・左・右：移動方向の辺（左なら左辺）を、その方向でいちばん近い線に揃える
  - 左上・右上・左下・右下：2つの辺を、それぞれの方向でいちばん近い線に揃える
  - 中央（十字）：中心を、ページ（またはマージンの内側）の中央に揃える
  - 水平方向中央・垂直方向中央：片方の軸だけ、中心をページ（またはマージンの内側）の中央に揃える
- ［中央揃えの基準］で、中央のボタンが揃える範囲を［ページ］か［マージン］（マージンガイドで囲んだ内側）から選ぶ
- 辺を揃える先は、ガイド（スプレッド・ページ・親ページ）・マージンガイド・ページのエッジ・裁ち落としのうち、いちばん近い線
- 辺を揃えるボタンは、続けて押すと次の線へ進む（例：マージン → ページのエッジ → 裁ち落とし）
- 辺を揃えるボタンを Option（Alt）＋クリックすると、いったん中央（［中央揃えの基準］の範囲の中央）に移したものとして、そこからいちばん近い線に揃える（矢印キーも Option と一緒に押すと同じ）
- オブジェクトごとに、それぞれいちばん近い線へ動かす
- ［選択をまとめて移動］で、選択全体の境界を基準に、相対位置を保ったまま全体を動かす
- パレットを選んでいるときは、矢印キーで上下左右のボタンと同じ操作ができる。Esc で閉じる
- 1回の操作が1回の取り消しにまとまる
- スクリプト冒頭の変数 `SW_ACTION`・`SW_FROM_CENTER`・`SW_MOVE_AS_UNIT`・`SW_CENTER_BASIS` の初期値を差し替えて実行すると、パレットを出さずにそのボタンの揃え方だけを実行する（LayoutKeys などで、ボタンごとにキーボードショートカットを割り当てられる）
- ［中央揃えの基準］・［選択をまとめて移動］とパレットの位置は、InDesign の終了まで覚える。日本語／英語の自動切り替え

### 使い方

1. スクリプトを実行してパレットを開く
2. 動かすオブジェクトを選択する（文字ツールで文字を選んでいるときは、そのテキストフレームが対象）
3. 揃え方のボタンをクリックする

### ボタンごとのキーボードショートカット

`SW_ACTION` が空（初期値）のときはパレットを開きます。ボタンの名前を入れて実行すると、パレットを出さずにそのボタンと同じ揃え方をします。

| 変数 | 値 |
| --- | --- |
| `SW_ACTION` | `upLeft`（左上）・`up`（上）・`upRight`（右上）・`left`（左）・`center`（中央）・`right`（右）・`downLeft`（左下）・`down`（下）・`downRight`（右下）・`centerH`（水平方向中央）・`centerV`（垂直方向中央） |
| `SW_FROM_CENTER` | `true` にすると、いったん中央に移してから揃える（Option＋クリックと同じ） |
| `SW_MOVE_AS_UNIT` | ［選択をまとめて移動］を `true`／`false` にする。空ならパレットの設定 |
| `SW_CENTER_BASIS` | ［中央揃えの基準］を `page`（ページ）／`margin`（マージン）にする。空ならパレットの設定 |

LayoutKeys では、このスクリプトを1つ登録し、詳細欄の「ホットキー」で［SW_ACTION の候補ごとに追加］を押すと、ボタンの数だけ行ができます。行ごとにショートカットを割り当てます（いったん中央から揃える行は、SW_FROM_CENTER を true にします）。ファイルそのものは書き換えません。`SW_CENTER_BASIS`・`SW_MOVE_AS_UNIT` が空のときは、パレットで選んだ［中央揃えの基準］・［選択をまとめて移動］を使います（InDesign の終了まで）。

### 制限事項・メモ

- 辺は線の太さを含む境界（表示上の境界）で測ります。
- 中央のボタンは、オブジェクトの中心があるページ（見開きでは左右のどちらかのページ）の中央、またはそのページのマージンの内側の中央に揃えます。中心がページの外にあるときは、いちばん近いページを使います。
- 揃える先の線が無いオブジェクトはその場に残します（斜めのボタンは、線がある方向だけ動きます）。どのオブジェクトも動かなかったときだけ、警告を表示します。
- ロックしたオブジェクト、ロックしたレイヤーのオブジェクト、アンカー付きオブジェクトは対象にしません。
- 非表示のレイヤーにあるガイドは使いません。親ページのガイドは、ページに直接当たっている親ページのものだけを使います（親ページの元になった親ページのガイドは使いません）。
- 段組みのガイドは使いません。
- パレットを開いたままスクリプトを再実行すると、前のパレットを閉じてから開き直します。
