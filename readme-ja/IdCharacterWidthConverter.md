# 文字の種類ごとに全角・半角を変換

[![Direct](https://img.shields.io/badge/Direct%20Link-IdCharacterWidthConverter.jsx-ffcc00.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/jsx/text/IdCharacterWidthConverter.jsx)

[![English](https://img.shields.io/badge/README-English-4b8bbe.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/readme-en/IdCharacterWidthConverter.md)

[![Direct](https://img.shields.io/badge/Back%20to%20home-All%20scripts-cccccc.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/README.md)

---

カタカナ・英数字・スペース・句読点・括弧・記号を、文字の種類ごとに「そのまま／半角／全角」を選んで変換します。数字の桁数による切り替え、句読点の種類の統一、括弧のまわりのスペースの削除もでき、縦組み用・欧文組版用などのプリセットで設定をまとめて切り替えられます。文字の書式（フォント・文字スタイルなど）はそのまま残ります。

### 主な機能

- 42 種類の行ごとに「そのまま／半角／全角」を選択。行は次のパネルに分けて表示
  - ［文字種］カタカナ・アルファベット・数字・スペース
  - ［句読点］和文の句読点、コンマ・ピリオド・コロン・セミコロン・感嘆符・疑問符、!?（?! も）、2個以上続く !
  - ［括弧］二重引用符・引用符、丸・角・波括弧、不等号、かぎかっこ
  - ［記号］ハイフン・アンダースコア・円マークなど 17 種
- 半角カタカナの濁音・半濁音（ｶﾞ・ﾊﾟ など）は 1 文字の全角（ガ・パ）にまとめて変換。全角から半角へは 2 文字に分けて変換
- !? と 2個以上続く ! はひとまとまりで扱い、「そのまま」なら感嘆符・疑問符の行の設定に関係なく元のまま残す
- 行のほかのオプション
  - ［文字種］数字は1桁を全角、2桁以上を半角にする／スペースは前後が和文の文字のときだけ変換
  - ［句読点］句読点の種類（，．と、。のどちらかにそろえる）
  - ［括弧］括弧の内側のスペースを削除／括弧の外側のスペースを削除／全角の引用符の字形（＂＇ または “ ” ‘ ’）
  - ［記号］全角のハイフンの字形（－・‐・−）／全角のチルダの字形（～・〜）
- 対象は［選択範囲］［ストーリー］［ドキュメント］から選択。表のセル・脚注の文字も変換
- ［除外するスタイル...］で選んだ段落スタイル・文字スタイルの文字は変換しない
- ［プリセット］で設定を切り替え。組み込みは「標準」「英数字・記号を半角」「英数字・記号を全角」「カタカナだけ全角」「縦組み用」「欧文組版用」の6つ。今の設定に名前を付けて［保存...］、自分で作ったプリセットは［削除］できる（今の設定に合うプリセットが無いときは「カスタム」と表示）
- Option キーを押しながらラジオボタンをクリックすると、そのパネルの行をすべて同じ選択肢にする
- ［デフォルトに戻す］で初期設定（カタカナは全角、英数字は半角、句読点・かぎかっこは全角、ほかはそのまま）に戻す
- 変換後に、行ごとの変換した数を表示
- 設定・対象・除外するスタイルは InDesign を終了するまで記憶。保存したプリセットは InDesign を再起動しても残る

### 使い方

1. 変換したい文字、テキストフレーム、または表のセルを選択する（ドキュメント全体なら選択しなくてよい）
2. スクリプトを実行する
3. ［プリセット］を選ぶか、行ごとに「そのまま／半角／全角」とオプションを選ぶ
4. ［対象］を選び、［変換する］をクリックする

### 制限事項・メモ

- 処理全体が 1 回の取り消しにまとまります。
- 処理の順番は、行の変換 → 句読点の種類 → 数字の桁数 → 括弧のまわりのスペースです。たとえば「,」を全角にし、句読点の種類を「、。にそろえる」にすると、「,」は「、」になります。
- テキストフレームを選択したときは、そのフレームを含むストーリー全体が対象です。
- 選べる［対象］は選択によって変わります。何も選択していないときは［ドキュメント］だけです。
- ［ドキュメント］では親ページの文字も変換します。ロックされたストーリー、ロック・非表示のレイヤーの文字は変換しません。
- カタカナの行には長音記号（ー／ｰ）・中黒（・／･）・単独の濁点と半濁点も含みます。カタカナを半角にすると、ひらがなや漢字に続く「ー」も半角になります。
- 半角カタカナにない文字（ヰ・ヱ・ヮ・ヵ・ヶ）はそのまま残ります。
- 「数字は1桁を全角、2桁以上を半角」では、3.5 や 1,000 のように区切りをはさむ数字はひとつながりとして数え、英字に続く数字（A4 など）は半角にします。オンのあいだ、数字の行の選択肢は使いません。
- 「スペースは前後が和文の文字のときだけ変換」の和文の文字は、かな・漢字・和文の約物・全角文字です。
- 「括弧の内側のスペースを削除」は、向きの無い " ' と不等号、アポストロフィと紛れる ‘ ’ を対象にしません。「括弧の外側のスペースを削除」は全角の括弧・かぎかっこだけが対象で、欧文の「word (note)」の空きは残します。
- 全角の引用符を “ ” ‘ ’ にしたときは、段落の中の順番で開き・閉じを決めます（1つ目が開き、2つ目が閉じ）。英数字にはさまれた ' はアポストロフィ（’）にします。半角にするときは “ ” ‘ ’ を " ' に戻します。
- ハイフン・チルダ・引用符を半角にするときは、選んでいる字形だけを半角にします（たとえば字形が「〜」なら、「～」は変換しません）。
- 句読点の行は「。」「｡」と「、」「､」の両方を変換し、かぎかっこの行は「「」「｢」と「」」「｣」を変換します。
- 「縦組み用」「欧文組版用」以外の組み込みのプリセットは、カタカナ・和文の句読点（。、）・かぎかっこを全角にし、スペースはそのままにします。「英数字・記号を半角／全角」は ASCII の句読点・引用符・括弧と円マークも同じ向きに変換します。
- 「縦組み用」は、数字を「1桁は全角、2桁以上は半角」（縦中横向け）、!? と 2個以上続く ! を半角、和文にはさまれたスペースを全角、チルダを波ダッシュ（〜）にし、カタカナ・句読点・括弧・記号を全角にします。英字・コンマ・ピリオド・引用符は、欧文の単語や 1,000 のような数字を崩さないようそのままにします。縦中横の設定はしません。
- 「欧文組版用」は、全角の英数字・記号・ASCII の句読点・括弧・スペース（U+3000）・円マークをすべて半角にし、カタカナ・和文の句読点（。、）・かぎかっこはそのままにします。
- 除外するスタイルは名前で覚えます。別のドキュメントで同じ名前のスタイルがあれば、そのスタイルも除外します。
- プリセットは `~/Library/Application Support/indesign-scripts/IdCharacterWidthConverter.json`（Folder.userData の下）に保存します。
