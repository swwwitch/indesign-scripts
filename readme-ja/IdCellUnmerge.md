表の結合セルを解除します。解除後のセルへ元のテキストを複製するかどうかと、対象範囲をダイアログで選べます。

![ダイアログ。上に解除後のテキストのパネル、下に対象のパネル](../png/ss-426-588-144-20260916-231523.png)

## 主な機能

- 解除後のテキストを「元のセルにのみ残す」「すべてのセルに複製」から選択
- 対象を「表全体」「選択セルのみ」から選択
- 表の一部を選んで実行したときは、［対象］が「選択セルのみ」で開く
- 複製先は、その結合セルの解除で生じたセルだけに限定
- 重複選択されたセルは 1 回だけ処理
- 各パネルにツールチップで補足を表示

## 使い方

1. 表、または表の中のセルを選択する
2. スクリプトを実行する
3. 解除後のテキストの扱いと対象範囲を指定して［OK］

## 制限事項・メモ

- 「すべてのセルに複製」を選ぶと、その結合セルの解除で生じたすべてのセルに同じテキストが入ります。隣接する別のセルには影響しません。
- 複製されるのは、結合セルが表示していたテキストです。書式は引き継がれず、プレーンテキストとして入ります。
- ［対象］の初期値が切り替わるのは、セルを選択して実行したときだけです。セル内にテキストカーソルを置いただけの状態では「表全体」で開きます。
- 1 セルの処理に失敗しても全体は止まりません。
- 全処理が 1 回の取り消しにまとまります。

## 更新履歴

### v1.0.2（2026-09-16）

- UI の文言を実際の動作に合わせて変更。「テキストを分配」は同じテキストの複製なので「すべてのセルに複製」、対になる選択肢は「元のセルにのみ残す」に
- 「結合」パネルの見出しを「解除後のテキスト」に変更。中身がテキストの扱いで、結合の設定ではなかったため
- ダイアログのタイトルと取り消し名を、InDesign のメニューに合わせて「セルの結合を解除」に変更
- 表の一部を選択して実行したとき、［対象］が「選択セルのみ」で開くように変更
- ［解除後のテキスト］［対象］の各パネルにツールチップを追加
- 表が見つからないときのアラートを、ダイアログを閉じる前に表示するように変更
- 変数名・関数名を実際の役割に合わせて整理（動作は変わりません）

### v1.0.1（2026-08-27）

- ［選択したセルのみ］で結合が解除されなかったり、別のセルのテキストが混ざって入る問題を修正。結合セルの `contents` が構成セルごとのテキストの配列で返るのを、文字列として扱っていたのが原因です
- 「テキストを分配」の対象を、その結合セルの解除で生じたセルだけに限定
- ［表全体］で結合セルを取りこぼすことがあった問題を修正。解除するたびにセル数が変わり、後続セルの参照がずれていました
- 全体を即時関数（IIFE）で囲み、グローバル変数の流出をなくした
