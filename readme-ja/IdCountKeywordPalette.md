# キーワードの件数をパレットで数える

[![Direct](https://img.shields.io/badge/Direct%20Link-IdCountKeywordPalette.jsx-ffcc00.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/jsx/text/IdCountKeywordPalette.jsx)

最大5つのキーワードが、選択中のストーリーまたはドキュメント全体にそれぞれいくつあるかを、常駐パレットで数えます。

### 主な機能

- キーワード欄は5つ。「取引」「取り引き」「取引き」のような表記の揺れを並べて、それぞれの件数を一度に数えられる
- 件数は各欄の右に、合計は［合計］の行に表示（例：「7 件（ストーリー）」）
- ［ほかのキーワードに含まれる分は数えない］（初期値オン）：「取引き」の中の「取引」のように、長いキーワードの一部として見つかった分は短いキーワードに数えない
- パレットは2カラム。右の［見つかった場所］に、見つかった文字ごとのページと前後の文字列を一覧表示（例：「1 | 前の【取引】の話」）
- 前後に表示する文字数は［前後の文字数］で指定（初期値2、0〜50）。変えると数え直さずに一覧だけ作り直す
- 一覧の行をクリックすると、その文字を選択して表示する
- ページ欄は、親ページなら「A-親ページ」、はみ出したテキストは「オーバーセット」、ページ外は「ペーストボード」
- 対象は［ストーリー］（選択した文字・テキストフレーム・表のセルを含むストーリー）と［ドキュメント］から選択
- 複数のストーリーを選んでいるときは、その合計を表示
- 表・脚注・非表示レイヤー・ロックしたレイヤーやストーリーの文字も数える
- オプションは［大文字と小文字を区別］［単語単位］［親ページを含む］（［親ページを含む］はドキュメントのときだけ）
- パレットを開いたまま、キーワードや選択を変えて何度でも数えられる
- ［選択文字を入れる］で、選択中の文字を最後に入力したキーワード欄（まだ入力していなければ最初の空欄）に入れる
- 前回のキーワード・対象・オプションを InDesign の終了まで記憶
- 日本語／英語 UI に対応

### 使い方

1. 数えたい文字を選択するか、対象のストーリーにカーソルを置く（ドキュメント全体で数えるなら選択は不要）
2. スクリプトを実行する（1段落に収まる文字を選んでいれば、最初の空欄に入った状態で開く）
3. キーワード（1〜5つ）・対象・オプションを決めて［数える］を押す（キーワード欄で return キーでも数える）
4. ［閉じる］または Esc キーで閉じる

### 制限事項・メモ

- ［ストーリー］は、［数える］を押した時点の選択で対象を決めます。テキストを選んでいなければ「テキストを選択してください。」と表示します
- キーワードの `^` は文字どおりに探します（`^p` などの特殊文字の指定は使えません）
- 数えたあと、［検索と置換］の検索文字列は空になります。検索オプションは元の値に戻します
- 一覧はキーワード欄の順、その中は見つかった順に並びます。表示は先頭の500件までです
- 一覧の改行は「¶」、タブは空白で表示し、ページ番号などの特殊文字は省きます
- 合計は各欄の件数を足したものです。同じキーワードを2つの欄に入れると二重に数えます
- パレットを開いたまま再実行すると、前のパレットを閉じてから開き直します
