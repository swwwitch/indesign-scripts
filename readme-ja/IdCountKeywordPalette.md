# キーワードの件数を数えて表記の揺れを統一

[![Direct](https://img.shields.io/badge/Direct%20Link-IdCountKeywordPalette.jsx-ffcc00.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/jsx/text/IdCountKeywordPalette.jsx)

最大5つのキーワードが、選択中のストーリーまたはドキュメント全体にそれぞれいくつあるかを常駐パレットで数え、該当箇所を一覧しながら表記の揺れを統一します。

### 主な機能

- キーワード欄は5つ。「取引」「取り引き」「取引き」のような表記の揺れを並べて、それぞれの件数を一度に数えられる
- 件数は各欄の右に、合計は［合計］の行に表示（例：「7 件（ストーリー）」）
- ［キーワード］パネルの［ほかのキーワードに含まれる分は数えない］（初期値オン）：「取引き」の中の「取引」のように、長いキーワードの一部として見つかった分は短いキーワードに数えない
- パレットは2カラム。右の［該当箇所］に、見つかった文字ごとのページと前後の文字列を一覧表示（例：「1 | 前の【取引】の話」）
- 前後に表示する文字数は［前後の文字数］のスライダーで指定（初期値3、0〜20）。離すと数え直さずに一覧だけ作り直す
- ［前後が改行のものは表示しない］（初期値オン）：直前か直後が改行（段落の改行・強制改行・段／フレーム／ページ区切り、またはストーリー・セルの先頭・末尾）のものを一覧に出さず、統一でも置き換えない（件数には含む）
- ［【】を付ける］（初期値オフ）：一覧で見つかった文字を【】で囲む
- 一覧の行をクリックすると、その文字を選択し、［表示倍率］のスライダーで決めた倍率（初期値200%、50〜800%）で表示する
- **除外**：一覧の行を選んで［除外する］を押すか、行をダブルクリックすると除外する（チェックが外れる）。除外した行は件数と［統一する］の対象から外れ、合計の行に「除外 1 件」と出る。もう一度押すと元に戻す。除外は数え直しや置き換えのあとも残る
- **まとめて統一**：キーワード欄の左のラジオボタンで統一先を選ぶと、ほかの欄の行に「→ 取引」が付く。［統一する］で、除外していない行をまとめて統一先に置き換える
- **1か所ずつ置き換え**：一覧で選んだ文字が［置換後］に入るので、直して［適用］を押す。置き換えたあとは、同じキーワードの次の行が選ばれる
- 置き換えは1回の取り消し（⌘Z）で戻せる。置き換えたあとは自動で数え直す
- ページ欄は、親ページなら「A-親ページ」、はみ出したテキストは「オーバーセット」、ページ外は「ペーストボード」
- 対象は［ストーリー］（選択した文字・テキストフレーム・表のセルを含むストーリー）と［ドキュメント］から選択（初期値はドキュメント）
- 複数のストーリーを選んでいるときは、その合計を表示
- 表・脚注・非表示レイヤー・ロックしたレイヤーやストーリーの文字も数える
- オプションは［大文字と小文字を区別］［単語単位］［親ページを含む］（ドキュメントのときだけ）［目次内は除外］（初期値オン。［目次の作成］で作った目次のストーリーは数えない）
- ［選択文字を入れる］で、選択中の文字を最後に入力したキーワード欄（まだ入力していなければ最初の空欄）に入れる
- 前回のキーワード・対象・オプション・統一先を InDesign の終了まで記憶
- 日本語／英語 UI に対応

### 使い方

1. 数えたい文字を選択するか、対象のストーリーにカーソルを置く（ドキュメント全体で数えるなら選択は不要）
2. スクリプトを実行する（1段落に収まる文字を選んでいれば、最初の空欄に入った状態で開く）
3. キーワード（1〜5つ）・対象・オプションを決めて［数える］を押す（キーワード欄で return キーでも数える）
4. 統一するなら、統一先のラジオボタンを選び、残したい行を［除外する］で外して［統一する］を押す。1か所ずつ直すなら、行を選んで［置換後］を直し［適用］を押す
5. ［閉じる］または Esc キーで閉じる

### 制限事項・メモ

- ［ストーリー］は、［数える］を押した時点の選択で対象を決めます。テキストを選んでいなければ「テキストを選択してください。」と表示します
- 数えたあとでキーワード・対象・検索のオプションを変えると、［数える］で数え直すまで［統一する］［適用］は押せません
- 数えたあとに本文を編集して文字が変わった箇所は、置き換えずに飛ばし、その件数を表示します
- 置き換えると文字は入れ替わりますが、文字の書式は置き換える前の先頭の文字のものになります
- キーワードの `^` は文字どおりに探します（`^p` などの特殊文字の指定は使えません）
- 数えたあと、［検索と置換］の検索文字列は空になります。検索オプションは元の値に戻します
- 一覧はキーワード欄の順、その中は見つかった順に並びます。表示は先頭の500件までです（［統一する］は表示していない分も置き換えます）
- 一覧の改行は「¶」、タブは空白で表示し、ページ番号などの特殊文字は省きます
- 合計は各欄の件数を足したものです。同じキーワードを2つの欄に入れると二重に数えます
- パレットの左下にバージョンを表示
- パレットを開いたまま再実行すると、前のパレットを閉じてから開き直します
