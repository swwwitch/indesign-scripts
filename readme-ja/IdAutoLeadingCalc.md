# IdAutoLeadingCalc

選択テキストの現在の行送り（絶対値）と文字サイズから行送り％を段落ごとに逆算し、自動行送りに切り替えます。

## 主な機能

- 段落ごとに「行送り ÷ 文字サイズ」で％を逆算し、自動行送り量として設定
- 行送りを「自動」に切り替え、基準位置を仮想ボディの上／右に設定
- テキスト範囲選択・テキストフレーム選択・グループ（ネスト含む）に対応
- 処理後に選択を選び直して文字パネルの表示を更新

## 使い方

1. 対象のテキストまたはテキストフレームを選択する
2. スクリプトを実行する

## 制限事項・メモ

- すでに自動行送りの段落は逆算できないためスキップします。
- ダイアログは表示せず、実行するとその場で適用します。
