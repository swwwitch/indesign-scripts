選択したフレーム内の画像の縮尺率を、パレットで数値・幅・高さ・PPI・プリセット・マージン幅・親フレームの段幅から指定して変更し、フレームを画像に合わせます。

![パレット。上から縮尺率・幅・高さ・PPI・ピクセル寸法、左に増減・幅に合わせる・基準点、右にプリセットのボタン、一番下に［縮尺率を整数に丸める］](../png/ss-630-1214-144-20260926-112121.png)

## 主な機能

値を変えるとその場でドキュメントに反映されるので、見た目や解像度を確かめながら縮尺率を決められます。パレットは開いたままにでき、画像を選び替えるだけで次々に作業できます。

### 表示と入力

- **縮尺率**：「今の縮尺率 → ［入力欄］%」（例：30% → ［57］%）
  - 今の縮尺率は、縦横が異なる場合は「25% / 30%」、画像ごとに異なる場合は「混在」
- **幅**・**高さ**：画像の幅・高さ（mm）。入力すると、その寸法になる縮尺率をフレームごとに求めます
- **PPI**：「元の PPI → ［有効 PPI の入力欄］」（例：144 → ［360］）。元はリンクパネルの「実際の PPI」、入力欄は「有効 PPI」（水平方向）。入力すると、その PPI になる縮尺率を求めます
- **ピクセル寸法**：画像の幅 × 高さ（px）

縮尺率・幅・高さ・PPI の欄は連動し、どれかを変えるとほかの欄も更新されます。入力欄はどれも↑↓キーで1、shift＋↑↓キーで10ずつ増減します。パレット下の［管理］で、増減・幅に合わせる・プリセットの各ボタンにキーボードショートカット（option／control＋英数字キー）を割り当てられます。初期設定は option＋1 が縮尺率 100%、option＋0 がマージン幅です。

### 縮尺率の指定

- **増減**：−10／+10、−5／+5、−1／+1
- **プリセット**：10%、15%、20%、25%、30%、35%、40%、50%、100%、200%、300%
- **幅に合わせる**
  - **マージン幅**：画像の幅がページのマージン幅に収まる縮尺率をフレームごとに求め、フレームの左端を左マージンにそろえます
  - **親フレーム**：テキストにアンカーされた画像を、親テキストフレームの段幅（インセットと段落の左右インデントを除く）に収まる縮尺率にします
- **基準点**：9軸で選んだフレームの位置（初期値は左上）が、縮尺を変えたあとも元の場所に残るように配置します
- **縮尺率を整数に丸める**（パレットの一番下・初期値オン）：適用する縮尺率を整数にします

### 確定と取り消し

- 選択を変えると、ここまでの変更を確定して、新しく選択したフレームを自動で読み込みます
- ウィンドウの閉じるボタンで閉じます（変更は残ります）
- 1つの対象への変更は、1回の取り消し（Cmd+Z）で元に戻せます
- 各項目にツールチップを表示（マウスを重ねると動作の説明が出ます）

## 使い方

1. 画像を配置したフレームを選択する（未選択のまま開き、あとで選択してもかまいません）
2. スクリプトを実行する
3. 縮尺率・幅・高さ・PPI のいずれかを入力するか、ボタンで指定する
4. 次の画像を選んで、3 を繰り返す
5. 終わったら、ウィンドウの閉じるボタンで閉じる

## 制限事項・メモ

- 対象は、画像または PDF を1点だけ配置した長方形のフレームです。楕円・多角形のフレームや、画像を直接選択した場合は対象になりません。
- 縦横の縮尺率が異なる画像も、変更すると縦横同じ縮尺率になります。今の縦横が異なる、または画像ごとに異なる場合、縮尺率の入力欄の初期値は 10% です。
- ［縮尺率を整数に丸める］がオンのとき
  - 縮尺率の入力値は四捨五入します
  - 幅・高さ・PPI の入力と［マージン幅］［親フレーム］は、はみ出さないよう（PPI は下回らないよう）切り捨てます
  - 増減の ±1 は整数に、±5・±10 は 5 や 10 の倍数へ寄せます（23% で +5 → 25%）
- オフのときは丸めません。入力した値や増減の結果をそのまま使い、幅・高さ・PPI や幅に合わせるときはぴったりの縮尺率にします。
- 幅・高さ・PPI の入力や［マージン幅］［親フレーム］で、求めた縮尺率がフレームごとに異なる場合、縮尺率の入力欄には「個別」と表示されます。
- アンカー付きのフレームは位置を動かしません（基準点も効きません）。［マージン幅］では、左右の位置は左マージンが優先されます。
- ［マージン幅］は、見開きの左ページでは内側・外側のマージンを入れ替えて計算します。
- ［親フレーム］は、アンカーされていないフレームとオーバーセットの画像を変更しません。当てはまるフレームが無いときは、ボタンを押せません。
- PDF は PPI とピクセル寸法を持たないため「—」と表示し、PPI を入力しても縮尺は変わりません。
- パレットを開いたままスクリプトを再実行すると、前のパレットを閉じて（変更は残して）開き直します。
- InDesign はモーダルダイアログの表示中にドキュメントを変更できないため、パレットにしています。
