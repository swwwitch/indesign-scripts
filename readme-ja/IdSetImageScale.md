選択したフレーム内の画像の縮尺率を、パレットで数値・プリセット・マージン幅・親フレームの段幅から指定して変更し、フレームを画像に合わせます。

![パレット。上から現在の縮尺率・変更後の縮尺率・元のPPI・編集後のPPI・ピクセル寸法、下に増減・幅に合わせる・プリセットのボタン](../png/ss-642-990-144-20260926-103616.png)

## 主な機能

値を変えるとその場でドキュメントに反映されるので、見た目や解像度を確かめながら縮尺率を決められます。

### 表示

- **現在の縮尺率**：選択中の画像の縮尺率。縦横が異なる場合は「25% / 30%」、画像ごとに異なる場合は「混在」
- **変更後の縮尺率**：適用する縮尺率の入力欄（↑↓キーで1、shift＋↑↓キーで10ずつ増減）
- **元のPPI**：画像そのものの解像度（リンクパネルの「実際の PPI」）
- **編集後のPPI**：縮尺率を反映した解像度（リンクパネルの「有効 PPI」）。値を変えるたびに更新
- **ピクセル寸法**：画像の幅 × 高さ（px）

### 縮尺率の指定

- **増減**：−10／+10、−5／+5、−1／+1。±5・±10 は 5 や 10 の倍数へ寄せます（23% で +5 → 25%）
- **プリセット**：10%、15%、20%、25%、30%、35%、40%、45%、50%、100%、200%、300%、400%、500%
- **幅に合わせる**
  - **マージン幅**：画像の幅がページのマージン幅に収まる縮尺率をフレームごとに求め、フレームの左端を左マージンにそろえます
  - **親フレーム**：テキストにアンカーされた画像を、親テキストフレームの段幅（インセットと段落の左右インデントを除く）に収まる縮尺率にします

### 確定と取り消し

- **［更新］**：ここまでの変更を確定し、いま選択しているフレームを読み込み直します
- **［キャンセル］**：最後に［更新］してから（または開いてから）の変更を取り消して閉じます
- ウィンドウの閉じるボタンで閉じると、変更を残します
- 変更は1回の取り消し（Cmd+Z）で元に戻せます
- 各項目にツールチップを表示（マウスを重ねると動作の説明が出ます）

## 使い方

1. 画像を配置したフレームを選択する（未選択のまま開き、あとで選択して［更新］を押してもかまいません）
2. スクリプトを実行する
3. 縮尺率を入力するか、ボタンで指定する
4. 仕上がりを確かめて、ウィンドウの閉じるボタンで閉じる（別の画像に続けるときは、選択し直して［更新］）

## 制限事項・メモ

- 対象は、画像または PDF を1点だけ配置した長方形のフレームです。楕円・多角形のフレームや、画像を直接選択した場合は対象になりません。
- 縦横の縮尺率が異なる画像も、変更すると縦横同じ縮尺率になります。現在の縦横が異なる、または画像ごとに異なる場合、変更後の縮尺率の初期値は 10% です。
- ［マージン幅］［親フレーム］の縮尺率は整数に切り捨てます。求めた値がフレームごとに異なる場合、入力欄には「個別」と表示されます。
- ［マージン幅］では、アンカー付きのフレームは位置を動かしません。見開きの左ページでは、内側・外側のマージンを入れ替えて計算します。
- ［親フレーム］は、アンカーされていないフレームとオーバーセットの画像を変更しません。当てはまるフレームが無いときは、ボタンを押せません。
- PDF は PPI とピクセル寸法を持たないため、「—」と表示します。
- パレットを開いている間に別の操作をすると、［キャンセル］でもそれより前の変更は戻りません。
- パレットを開いたままスクリプトを再実行すると、前のパレットを閉じて（変更は残して）開き直します。
- InDesign はモーダルダイアログの表示中にドキュメントを変更できないため、プレビューのためにパレットにしています。
