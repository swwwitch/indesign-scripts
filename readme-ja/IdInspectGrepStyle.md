ドキュメント内の段落スタイルに設定された正規表現スタイル（GREP スタイル）を一覧表示し、テキストへ書き出します。

## 主な機能

- 段落スタイル／適用される文字スタイル／正規表現を 3 列で表示
- 任意の列でソート
- 一覧全体と、重複を除いた正規表現リストをテキストとして書き出し
- 書き出し先はデスクトップ（ファイル名にドキュメント名とタイムスタンプを付与）

## 使い方

1. 対象のドキュメントを開く
2. スクリプトを実行する
3. 必要に応じて［テキストに書き出し…］

## 制限事項・メモ

- 正規表現スタイルが 1 件も無い場合はメッセージを表示して終了します。
