# カーソル位置にアンカー付き長方形とテキストアンカーを作成

[![Direct](https://img.shields.io/badge/Direct%20Link-IdInsertAnchoredRectangle.jsx-ffcc00.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/jsx/document/IdInsertAnchoredRectangle.jsx)

[![English](https://img.shields.io/badge/README-English-4b8bbe.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/readme-en/IdInsertAnchoredRectangle.md)

[![Direct](https://img.shields.io/badge/Back%20to%20home-All%20scripts-cccccc.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/README.md)

カーソルを置いた位置に、アンカー付き（カスタム）でプリントしない小さな長方形と、その直前のテキストアンカーを作成します。

テキストアンカーの名前と長方形の塗り・線・位置（ページの左／右）はダイアログボックスで指定できます。ハイパーリンクや相互参照の行き先として使いながら、紙面上では長方形で位置を確かめられます。

### 主な機能

- カーソル位置（テキストを選択しているときはその先頭）に、12×12 pt の長方形を、アンカー付きオブジェクト（［アンカー付きオブジェクトオプション］の位置は「カスタム」）として挿入
- 長方形の縦位置はカーソルのある行に合わせる（下端を行のベースラインに揃える）。文章が流れても行に付いて動く
- 長方形の横位置は、ダイアログボックスで［ページの左］［ページの右］から選ぶ（初期値は左）。ページの端とマージンの中間に長方形の中心を置く。見開きでも左右は入れ替わらない
- 塗りと線は、ドキュメントのスウォッチから選ぶ。初期値は塗り「C=0 M=100 Y=100 K=0」（ドキュメントに無ければ作成）、線［なし］
- ポップアップメニューの横に、選んだスウォッチの色見本を表示（画面表示用の簡易的な色。［なし］は白）
- 線を選んだときは線幅を指定できる（初期値 0.5 pt）。線が［なし］のときは線幅の欄は無効
- 長方形は［プリントしない］に設定（［属性］パネル）。プリントや PDF 書き出しには出ない
- 長方形のマーカー文字の直前にテキストアンカーを作成
- テキストアンカー名はダイアログボックスで変えられる。初期値は「p＋ページ番号＋_＋通し番号」（例：`p12_01`。通し番号はそのページで空いている最小の番号）
- 同じ名前を長方形のスクリプトラベルにも入れる
- 作成後は長方形を選択
- 取り消しは1回で元に戻る

### 使い方

1. 行き先にしたいテキストの位置に文字ツールでカーソルを置く（またはテキストを選択する）
2. スクリプトを実行する
3. ダイアログボックスで名前・塗り・線・位置を確かめて［OK］をクリックする
4. 長方形とテキストアンカーができる
5. ［ハイパーリンク］パネルや［相互参照を挿入］で、このテキストアンカーを行き先に選ぶ

### 制限事項・メモ

- テキストフレームを選択ツールで選んだ状態や、オブジェクトを選んだ状態では実行できません。
- ペーストボード上やオーバーセットのテキストでは使えません。
- 横位置は作成時のページのマージンから決めます。文章が流れて左右のマージンが異なるページへ移ると、中間からずれます。
- 名前が空のとき、同じ名前のテキストアンカーがあるとき、線幅が正しくないときは、［OK］でメッセージを出してダイアログボックスに戻ります。
- 大きさ・塗りの初期値・線幅の初期値・位置の初期値・名前の形は、スクリプト冒頭の基本設定で変えられます。
- 実機での動作は未確認です。
