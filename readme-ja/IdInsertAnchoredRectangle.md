# カーソル位置にアンカー付き長方形とテキストアンカーを作成

[![Direct](https://img.shields.io/badge/Direct%20Link-IdInsertAnchoredRectangle.jsx-ffcc00.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/jsx/document/IdInsertAnchoredRectangle.jsx)

カーソルを置いた位置に、アンカー付き（カスタム）でプリントしない小さな長方形と、その直前のテキストアンカーを作成します。

テキストアンカーの名前と長方形の塗り・線はダイアログボックスで指定できます。ハイパーリンクや相互参照の行き先として使いながら、紙面上では長方形で位置を確かめられます。

### 主な機能

- カーソル位置（テキストを選択しているときはその先頭）に、12×12 pt の長方形を、アンカー付きオブジェクト（［アンカー付きオブジェクトオプション］の位置は「カスタム」）として挿入
- 塗りと線は、ドキュメントのスウォッチから選ぶ。初期値は塗り「C=0 M=100 Y=100 K=0」（ドキュメントに無ければ作成）、線［なし］
- 線を選んだときは線幅を指定できる（初期値 0.5 pt）
- 長方形は［プリントしない］に設定（［属性］パネル）。プリントや PDF 書き出しには出ない
- 長方形のマーカー文字の直前にテキストアンカーを作成
- テキストアンカー名はダイアログボックスで変えられる。初期値は「p＋ページ番号＋_＋通し番号」（例：`p12_01`。通し番号はそのページで空いている最小の番号）
- 同じ名前を長方形のスクリプトラベルにも入れる
- 作成後は長方形を選択
- 取り消しは1回で元に戻る

### 使い方

1. 行き先にしたいテキストの位置に文字ツールでカーソルを置く（またはテキストを選択する）
2. スクリプトを実行する
3. ダイアログボックスで名前と塗り・線を確かめて［OK］をクリックする
4. 長方形とテキストアンカーができる
5. ［ハイパーリンク］パネルや［相互参照を挿入］で、このテキストアンカーを行き先に選ぶ

### 制限事項・メモ

- テキストフレームを選択ツールで選んだ状態や、オブジェクトを選んだ状態では実行できません。
- ペーストボード上やオーバーセットのテキストでは使えません。
- 同じ名前のテキストアンカーがあるときは、［OK］でメッセージを出して名前の入力に戻ります。
- 大きさ・塗りの初期値・線幅の初期値・名前の形は、スクリプト冒頭の基本設定で変えられます。
- 実機での動作は未確認です。
