# アンカー付きオブジェクトをまとめて解除

[![Direct](https://img.shields.io/badge/Direct%20Link-IdReleaseAnchoredObjects.jsx-ffcc00.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/jsx/frame/IdReleaseAnchoredObjects.jsx)

選択したフレーム、指定したページ、またはドキュメント内のアンカー付きオブジェクトを、アンカーやフレームの種類で絞り込んで解除します。

![ダイアログ。上から対象、アンカーの種類、フレームの種類、解除後の4パネル](../png/ss-682-960-144-20260925-104233.png)

## 主な機能

［オブジェクト］→［アンカー付きオブジェクト］→［解除］と同じ処理を、選択やメニュー操作なしでまとめて実行します。解除したオブジェクトの位置は変わりません。

### 対象

- **選択したフレーム**：選択中のアンカー付きオブジェクトに加えて、選択したテキストフレームやテキストに含まれるものも対象
- **現在のページ**：横にページ番号を表示。書き換えると別のページを対象にできます（↑↓キーで前後のページ、shiftキー併用で10ページずつ）
- **ドキュメント**：ドキュメント内のすべて。［親ページを含める］で親ページ上のものも対象にできます

### 絞り込み

- **アンカーの種類**：インライン／行の上／カスタム
- **フレームの種類**：テキストフレーム／グラフィックフレーム（長方形・楕円・多角形。画像の入っていないフレームも含む）
- チェックボックスは option＋クリックでそれ以外をオフ、もう一度 option＋クリックですべてオン

### 解除後

- ［解除したオブジェクトを選択］で、終了後に解除したものを選択（移動や整列にそのまま続けられます）
- 解除した件数と、解除できずに飛ばした件数を表示
- 一連の処理は1回の取り消し（Cmd+Z）で元に戻せます
- 各項目にツールチップを表示（マウスを重ねると動作の説明が出ます）

## 使い方

1. 必要に応じてアンカー付きオブジェクト（またはそれを含むテキストフレームやテキスト）を選択する
2. スクリプトを実行する
3. 対象・アンカーの種類・フレームの種類を選んで［OK］

## 制限事項・メモ

- 初期値は、選択にアンカー付きオブジェクトがあれば［選択したフレーム］、なければ［現在のページ］です。選択にアンカー付きオブジェクトがないときは［選択したフレーム］を選べません。
- 種類のチェックボックスと［解除したオブジェクトを選択］はオン、［親ページを含める］はオフが初期値です。
- ［アンカーの種類］［フレームの種類］は、それぞれ1つ以上オンにしないと［OK］を押せません。
- 存在しないページ番号を入力して［OK］を押すと、メッセージを表示してダイアログに戻ります。
- ［現在のページ］では、オーバーセットのテキストやペーストボード上のテキストフレームに含まれるものは対象になりません。
- 解除できないもの（ロックされたオブジェクトなど）は飛ばします。
- 解除したものが複数のスプレッドにまたがるときは、表示中のスプレッドのものだけを選択します。
