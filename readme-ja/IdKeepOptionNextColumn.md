選択した段落の「段落の開始位置」を「次の段（フレーム）」に設定します。

### 主な機能

- `startParagraph` に `NEXT_COLUMN` を設定
- 段落開始位置を設定できない選択の場合はメッセージを表示

### 使い方

1. 対象の段落にカーソルを置くか、段落を選択する
2. スクリプトを実行する

### 制限事項・メモ

- テキストフレームの最終行などを次の段や次のフレームへ送りたいときに使います。
