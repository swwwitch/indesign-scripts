# ファイル名をセグメント単位で編集してリネーム・保存

[![Direct](https://img.shields.io/badge/Direct%20Link-IdFileNameManager.jsx-ffcc00.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/jsx/document/IdFileNameManager.jsx)

[![Direct](https://img.shields.io/badge/Back%20to%20home-All%20scripts-cccccc.svg)](https://github.com/swwwitch/indesign-scripts/blob/main/README.md)

アクティブなドキュメントのファイル名を、ベース・サブテキスト・ステータス・日付・連番・バージョンのセグメント単位で編集し、リネーム／別名保存／コピー保存を行います。

### 主な機能

- セグメントは base / title / status / timestamp / page / version。並び順もカスタマイズ可能
- ステータス（wip / draft / review / approved / flattened など）をドロップダウンから挿入
- 連番（page01 / page001）は保存時にフォルダー内の最大値 +1 へ自動繰り上げ
- バージョンは v1 / v01 / v001 の書式を選べ、フォルダー内の最大値 +1 まで自動繰り上げ
- 区切り記号の統一、NFC 正規化、丸数字や法人略記の ASCII 化などのファイル名整形

### 使い方

1. 対象のドキュメントを開く
2. スクリプトを実行する
3. モードと各セグメント、並び順を指定して［OK］

保存先はダイアログを開く前に確定します。プレビューに出る繰り上げ後の番号と、実際に保存されるファイル名を一致させるためです。未保存ドキュメントの場合は、ダイアログが開く前に保存先フォルダーを訊かれます。

### 動作：3 つの保存方法

| 動作 | 挙動 |
| --- | --- |
| 元ファイルをリネーム | 新しい名前で保存したあと、元ファイルをゴミ箱へ移動 |
| 別名で保存 | 新しい名前で保存。元ファイルは残り、作業中のドキュメントが新ファイルに切り替わる |
| コピー（複製）を保存 | 元ファイルに上書き保存したうえで、別名のコピーを作成。作業中のドキュメントは元ファイルのまま |

初期選択は常に「別名で保存」です。

保存されるのは常に InDesign 形式（.indd）なので、**.indd 以外の書類（IDML など）を開いているときは「元ファイルをリネーム」と「コピー（複製）を保存」が選べません。** 前者は形式を変換したうえで原本を削除してしまい、後者は中身が元の形式のまま拡張子だけ .indd のファイルができてしまうためです。この場合は「別名で保存」を使ってください（原本は残ります）。

### タイムスタンプ

「なし」「YYYYMMDD」「YYYY-MM-DD」から選択します。「時刻も付与」で末尾に `-HHMM` が付きます。

タイムスタンプが「なし」のまま「時刻も付与」をオンにすると時刻がどこにも出ないので、**オンにした時点で自動的に「YYYYMMDD」が選ばれます**。そのあと明示的に「なし」へ戻す操作は妨げません。

### 自動繰り上げ

連番とバージョン番号は、同じフォルダー内を実際にスキャンして繰り上げます。走査の対象は「同じ前後（prefix / suffix）を持つ .indd ファイル」なので、無関係なファイルの番号には引きずられません。

採番は整形（クリーン・変換・区切り記号統一）の**あと**に行います。フォルダー内の既存ファイル名は整形済みで保存されているため、整形前の名前で照合すると最大値を取りこぼして繰り上がらないことがあるためです。

v 番号・連番として認識するのは、**区切り（`-` `_` `.`）か名前の端に挟まれたもの**だけです。`rev1-catalog-v02.indd` の `rev1` は「revision の 1」であって v 番号ではないので、繰り上がるのは末尾の `v02` のほうです。

フォルダーの一覧は、ダイアログを開いている間は 1 度だけ読み込んでプレビューに使い回し、［OK］を押したあとの実際の採番では読み直します。数千ファイルのフォルダーで 1 打鍵ごとに全走査が走るのを避けるためです。

### 制限事項・メモ

- 元ファイルに v 番号が無い場合、バージョンは v01 形式で付与されます。
- 設定はスクリプト実行のたびに保存され、次回の初期値になります。
- 記号だけ・絵文字だけの名前は整形の結果が空文字になるため、保存せずエラーを出します。
