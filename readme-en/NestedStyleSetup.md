# NestedStyleSetup

Applies and manages GREP styles on paragraph styles. Identical to GrepStyleApplier.jsx apart from the filename.

## Features

- Choose from saved rules or add custom ones
- Select or create the character style
- Select multiple target paragraph styles

## Usage

1. Open the target document
2. Run the script
3. Choose the rule, character style and target paragraph styles, then click OK

## Notes and limitations

- Identical to GrepStyleApplier.jsx; using just one of the two is recommended.
