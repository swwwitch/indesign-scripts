An alternate build of IdAutoParagraphStyleGenerator with the same behaviour: it generates paragraph styles per font, size and leading combination.

## Features

- Only font family/style, point size and leading are considered
- Grouping is normalized to points
- Style names follow the text-size unit (pt or Q)

## Usage

1. Open the target document
2. Run the script
3. Check the created and applied counts in the result dialog

## Notes and limitations

- Nearly identical to IdAutoParagraphStyleGenerator.jsx; using just one of the two is recommended.
