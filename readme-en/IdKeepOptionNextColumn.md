Sets the Start Paragraph option of the selected paragraph to Next Column (Frame).

## Features

- Sets `startParagraph` to `NEXT_COLUMN`
- Reports when the selection does not support the start-paragraph option

## Usage

1. Place the cursor in the paragraph or select it
2. Run the script

## Notes and limitations

- Useful for pushing the last line of a text frame into the next column or frame.
