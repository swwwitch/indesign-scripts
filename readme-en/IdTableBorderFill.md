Adjusts table-cell borders with a live preview, letting you set the scope, weight, colour and tint.

## Features

- Scopes: all, outer only, inner only, horizontal only, vertical only, top & bottom, left & right, remove side borders, clear all
- Keyboard shortcuts for the scope (A/E/I/H/V/U/L/R/C)
- The weight follows the document's stroke-weight unit, with presets and arrow-key stepping
- Border colour from a document swatch, plus a 0-100% tint
- A Preview toggle button switches the screen mode

## Usage

1. Select the table cells you want to change
2. Run the script
3. Set the scope, weight, colour and tint, then click OK

## Notes and limitations

- Facing edges of adjacent selected cells are handled together, so no doubled lines appear.
- Turn off Clear Before Apply to overwrite while keeping the current borders.
