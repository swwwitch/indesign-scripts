# InspectGrepStyle

Lists the GREP styles defined on the document's paragraph styles and exports them as text.

## Features

- Shows paragraph style, applied character style and GREP expression in three columns
- Sort by any column
- Exports both the full list and a deduplicated list of GREP expressions
- The export goes to the Desktop, named after the document plus a timestamp

## Usage

1. Open the target document
2. Run the script
3. Click Export to Text if you need a file

## Notes and limitations

- If the document has no GREP styles, the script reports it and stops.
