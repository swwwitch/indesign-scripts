Builds a type scale from a base size and ratio, then applies it to the body, heading and caption paragraph styles.

## Features

- Set the base (body) size, the scale ratio, the number of heading levels and the size rounding
- Fonts can be shared between body and headings, specified separately, or left unchanged
- Set body and heading leading (%), space after (%), and the kerning method
- Preview the size and leading for h1-h6, body and caption
- Live preview updates as you adjust the settings

## Usage

1. Open the target document
2. Run the script
3. Set the base size and ratio, adjust while watching the preview, then click OK

## Notes and limitations

- Headings are set to left alignment; body text and captions use left-justified alignment.
- Closing the dialog clears overrides and applies the final settings.
- See IdTypeScaleStyleApplier.jsx for a more feature-rich variant.
